# welcome to our tapakila project

#### to run this project :
- add a file named : **.env.local** in the source of the project
- add this content in the file : 
```
NEXT_PUBLIC_API_URL=http://localhost:3000/api
```
*PS* : *the url is just for mock test yet*
- do :
```
- npm i
- npm run dev 
```
- click to the 
```
- Local:        http://localhost:3000  
```
